# Thalia IoT - ESP32 工业传感器网关

这是一个基于 ESP32 的工业级温湿度监测项目，使用了 FreeRTOS 实时操作系统。

## ✅ 运行状态
代码运行稳定，串口持续输出温湿度数据：

![串口运行截图](images/ESP32-output.png)

## 🛠️ 核心技术栈
*   **主控芯片**：ESP32
*   **操作系统**：FreeRTOS (多任务调度)
*   **传感器**：DHT11/DHT22 (温湿度)
*   **数据存储**：EEPROM (参数持久化)
*   **通信协议**：Modbus RTU (RS485) / CRC16 校验

## 📝 功能特性
*   双核任务分离：采样任务与通信任务互不阻塞。
*   数据滤波：读取传感器时进行有效性校验，防止脏数据。
*   掉电保护：关键参数存储在 EEPROM 中，重启不丢失。
