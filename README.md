# 🏭 基于 ESP32 的工业级环境监测与边缘计算网关

本项目基于 **ESP32 + FreeRTOS**，实现工业现场温湿度数据的实时采集、本地边缘计算与 Modbus 协议上报，适用于智能制造与新能源场景。

## 🛠️ 核心技术栈

| 类别 | 技术 |
|---|---|
| 主控 | ESP32（双核） |
| 操作系统 | FreeRTOS |
| 通信协议 | Modbus RTU / TCP |
| 传感器 | DHT11 / DHT22 |
| 数据存储 | EEPROM（掉电保护） |
| 校验机制 | CRC16 |

---

## 📐 功能特性

- ✅ 多任务采集：采样 / 通信 / 看门狗任务解耦
- ✅ 工业协议：支持 Modbus 寄存器映射
- ✅ 边缘计算：阈值判断、异常缓存
- ✅ 抗干扰：电源波动下 EEPROM 数据完整性校验
- ✅ 可扩展：可接入 SCADA / 云平台
